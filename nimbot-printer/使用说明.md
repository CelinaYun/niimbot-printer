# NIIMBOT 打印助手

在 Windows 电脑上直接给 **NIIMBOT D110 / D11** 标签打印机排版并打印，
支持 **蓝牙 BLE** 和 **USB 串口** 两种连接方式。

**横版文字标签**：在一条长纸带上横向写字，一行写满再换行，就跟平常写标签一样。

---

## 一、准备

1. 电脑需要 **Windows 10 / 11**。
2. 打印机 **开机**，装好标签纸。
3. 用蓝牙时：**先关掉手机上的 NIIMBOT App**，它会占住连接。
4. **不要**在 Windows 蓝牙设置里手动配对打印机。程序用的是「免配对直连」，
   手动配对反而会导致连接失败。如果之前配对过，请先删除该设备。

> **本文件夹里已经建好了 `.venv` 运行环境**，在当前这台电脑上直接双击启动即可，
> 不用再装 Python。
>
> 如果你把整个文件夹拷到**别的电脑**上，那边需要先装 **Python 3.10 以上**：
>
> 1. 打开 <https://www.python.org/downloads/>，下载 Python 3.10 或更新版本
> 2. 运行安装包，**务必勾选 "Add python.exe to PATH"**
> 3. 再双击启动脚本，它会自动重建运行环境
>
> 注意：Windows 自带的「python.exe」（开始菜单搜出来的那个）只是**微软商店的占位符**，
> 不是真正的 Python，程序会检测出来并提示安装。这是正常现象，按上面的步骤装一次就好。

## 二、启动

双击 **`启动打印工具.bat`**。
第一次运行会自动安装依赖，稍等片刻；之后启动就很快。

### 切换中英文

右上角有 **ZH / EN** 两个小按钮，点一下立刻切换，**不用重启**——
界面会整页重画，正在输入的文字、选好的设置、日志都会保留。
选择会记住，下次打开还是上次那个语言。

英文界面里英文和数字用 Nothing 的 NType 82 Mono，中文仍是微软雅黑
（官方字体没有中文字形，强行用会掉成宋体）。

### 切换深色 / 浅色

右上角「浅色 / 深色」按钮一键切换，同样即时生效、重启后保持。
深色是纯黑画布，浅色是浅灰画布 + 白卡片；红色始终只出现在能点的地方。
按钮上写的是**点一下会变成什么**。

窗口内容装不下时，右侧会出现细滚动条 —— 1366×768 这类小屏也能上下翻到全部控件，不会被裁掉。
上次连过的打印机会在启动后自动试连一次；连不上只写一行日志，点「连接」手动重试即可。

## 三、连接打印机

1. 顶部选择连接方式：**蓝牙** 或 **USB 串口**。
2. 点 **扫描**，在下拉框里选中你的打印机（蓝牙设备名一般以 `D110` / `D11` 开头，
   USB 会显示 `COMx — ...`）。
3. 点 **连接**。标题栏变绿并显示型号 ID、电量、固件版本即为成功。

> **USB 连不上？** 部分 D110 的 USB 只供电不传数据，这时只能用蓝牙。
> 插上后在「设备管理器 → 端口 (COM 和 LPT)」里看到 COM 口才能用 USB。


## 四、打标签

界面是 **Nothing OS** 风格：纯黑画布 + 深灰卡片 + 一点信号红（#D71921）。
红色只出现在「能点的地方」（主按钮、选中项、卡片标题前的指示点），
其余全交给黑白灰分层，没有渐变和阴影。左边写字，右边设置。

字体也用 Nothing 官方那套：顶栏 **Ndot 55** 点阵，数字和技术标签用 **NType 82 Mono**
（打字机等宽）。官方字体只有拉丁字形，所以中文回退到微软雅黑。字体文件放在
`assets/fonts/`，启动时只在内存里临时注册，**不会装进你的系统**，关掉就消失。

### 左边：写字

在「输入文字」的框里直接打字，**每行一句**，文字沿标签长度方向横向打印。
预览会实时显示标签长什么样。字打错了直接改，跟记事本一样。

下面的**附加内容（可选）**可以不填；填了就在标签右侧（更靠后的位置）加上：

- **二维码**：填内容就生成，可以调大小
- **条码**：填内容就生成，可选 Code128 / EAN-13 / UPC-A / Code39
- **图片**：选一张 PNG/JPG，自动缩放到标签宽度；也可以**截图后按 Ctrl+Shift+V 直接粘贴**
- **排列**：多个附件同时存在时，决定它们从左到右的顺序

### 批量打印（一行一张）

勾选文字框下方的 **每行打一张**，就按行拆开：

```
CPU_X86_Ryzen 5 216     ← 第 1 张
CPU_X86_Ryzen 7 8845    ← 第 2 张
SSD_1TB_M2_2280         ← 第 3 张
```

点一次打印，三张依次出去，不用改一次打一次。空行自动忽略；预览显示第一张，
下方会写「预览第 1 张 / 共 3 张」。

> 份数在批量模式下对**每一张**生效：3 行 × 2 份 = 6 张。

### 模板（把常用内容存起来）

同一套内容要反复打时，点 **存为模板** 起个名字（比如「CPU 长型号」），
以后在「模板」下拉框里选一下就能填回来；不用的模板选中后点「删除」。

**已经预置了 6 个**，打开下拉框就能用：

| 模板 | 内容 |
| --- | --- |
| 资产标签 | ASSET / AV-0001234 / 张三 / 日期 |
| PCBA 料号 | MODEL-A / PCBA-0001234 / A0 / 日期 |
| CPU 型号 | CPU Ryzen5 216 / 4.70GHz 6CORE / 100-000002278 |
| SSD 标签 | SSD_1TB_M2_2280 / SN:ABC123456 / 日期 |
| 端口标识 | LAN-01 / SW-A12 / Gi0/1 |
| 样机勿动 | SAMPLE / DVT-01 / 请勿移动 |
| 资产·分栏 | ASSET ┄ 资产编号 / 负责人 ┄ 日期 |
| 料号·分栏 | MODEL-A ┄ PCBA 料号 / 版本 ┄ 日期 |
| 工牌·分栏 | 姓名 ═ 部门 ┄ 日期 |

内容里的 `{date}` 套用时自动换成当天日期（如 2026-11-04），
`{time}` 换成时间，`{year}` 换成四位年份 —— 日期类标签不用每次手改。

#### 分隔栏

想让标签内容分成几块，在文字里单独占一行写 `---` 或 `===`：

```
ASSET
---
AV-0001234
张三
---
2026-11-04
```

- `---`（三个以上减号）画**细线**
- `===`（三个以上等号）画**粗线**
- 线的长度会**自动撑满可用宽度**，不用手打一排横线去凑长度
- 行高和普通文字行一样，所以它会计入「能放几行」

> 带分隔栏的模板行数较多（5~6 行），**横版放不下**（12 mm 高只能排 2~3 行），
> 会自动缩成很小的字。这类模板请配合**竖版**使用。

内置模板可以直接改（存同名会覆盖）或删掉，**删了就不会再自己回来**。
模板和上次的文字都存在 `打印设置.json` 里，换电脑时把这个文件一起带走即可。


### 右边：设置

| 设置 | 说明 |
| --- | --- |
| 标签长度 | 30 / 40 / 50 / 75 / 109 mm，或自定义。**要和你装的纸一致** |
| 字号 | 8–48，越大越清楚但一行放的字越少。**放不下时会自动缩小并把实际字号写回框里**，不会被「框里写 40、实际印 28」骗到 |
| 对齐 | 文字靠左 / 居中 / 靠右 |
| 纸张类型 | 间隙标签（带底纸）/ 透明 / 连续 |
| 份数 | 打几份（超过 10 份会先确认一次） |
| 浓度 | 分段档位「浅 / 标准 / 深」（D110_M 五档），旁边标出实际数值 |
| 打印方向、打印协议 | 收在 **高级 / 校准** 里，平时不用展开。收起时右侧会显示当前值 |

然后点大大的 **打印** 按钮。

### 标签长度 / 纸张尺寸

**连接后程序会自动读取纸卷上的 RFID 标签**，把标签长度设成和纸一致，
日志里会写一行，例如：

```
已按检测到的纸张设置标签长度 30 mm（纸宽约 15 mm，间隙 2.0 mm）
```

这样就不用手填了。**如果你的纸卷不带 RFID**（程序会提示"未读到 RFID 纸张信息"），
请手动把「标签长度」改成纸卷上印的尺寸——**填错会导致内容被裁掉**：

> 例如纸是 30 mm 长，但标签长度填了 40 mm —— 内容按 40 mm 排版，
> 打到 30 mm 的纸上就有一截出不来。**典型症状是某个字缺半边**。

预览下方的红色警示会在内容超出时提示，务必留意。

**你这台机器用的 T15×30（30×15 mm）纸**：连接后标签长度会自动变成 30，
字太多就会提示超出——这时要么缩字号、要么减内容、要么换更长的纸。

### 容量与边界警示

预览下方有两行提示：

- **灰色那行**是当前容量，例如 `40 mm 标签 · 字号 28 · 每行约 11 字 · 1/2 行`
  —— 一眼能看出还能放几行、每行几个字。
- **红色那行**是超范围时的警示，一行一条，例如：

| 警示 | 含义 | 怎么办 |
| --- | --- | --- |
| `字号 120 太大——标签宽度只有约 84 点` | 字比标签还高 | 字号调到 80 以下（12 mm 纸最大约 84） |
| `5 行放不下（字号 28 最多 2 行）` | 行数超出标签宽度 | 减行，或换小字号（会自动缩，但会提示你） |
| `第 1 行「…」过长约 504 点` | 单行顶出标签长度 | 缩短这一行，或换更长标签 / 缩小字号 |
| `文字超出标签长度` | 内容总量超出 | 换更长标签，或减内容 / 缩字号 |

没超范围时显示绿色的 **✓ 内容在标签范围内**。

### 字的方向不对（镜像 / 颠倒）

打印头的点序方向在不同机器上可能相反，纸上字反了是正常的，换一下就行。

**预览显示的就是将要出纸的样子**——两者用的是同一套变换，所见即所得。
所以只要展开「高级 / 校准」，在「打印方向」里换，**换到预览里的字读着顺**，打出来就一定是正的：

| 选项 | 预览 / 纸上会是 |
| --- | --- |
| **正常**（默认） | 和你排的一样 |
| 左右翻转 | 左右镜像 |
| 上下翻转 | 上下颠倒 |
| 旋转 180° | 转了 180° |

> 预览区显示的就是**出纸的样子**——它和打印走同一套方向换算，逐像素一致。
> 所以一般保持「正常」即可；就算换了别的选项，预览也会跟着变，
> 看到什么就是打出来的什么，不必再靠试打去找方向。

### 对齐

左 / 中 / 右对齐按**文字的实际墨迹**定位（不是字形原点），
所以居中就是真的居中，不会偏。测试里用像素级校验过：40 mm 标签居中误差 ≤ 0.5 点。

### 表情和符号

文字里可以直接放 emoji：按 **Win + 句号** 打开表情面板，或者从微信、网页里复制粘贴。

| 能正常打出来 | 打不出来 |
| --- | --- |
| 😀 👍 ⭐ ✅ ❌ ⚠ ★ ♥ ✓ → ← ● ■ ▲ | 彩色、肤色、以及「👨‍👩‍👧」「🇨🇳」这类组合 emoji |

热敏打印机只有黑白两色，emoji 会被渲染成**单色轮廓**。程序内部用的是 Windows
自带的 Segoe UI Symbol 字体，实测 42 个常用符号全部支持；中文和英文仍走雅黑/等宽字体，
两者在一行里自动拼接。

> 12 mm 的纸很窄，一个 emoji 差不多占一个字的位置。字打太大时会被自动缩小，
> 或者切到竖版分担行数。

### 竖版：竖着贴的标签

「打印设置」最上面有 **版式** 开关，横版 / 竖版随时切，预览立刻跟着变。

| 版式 | 文字怎么排 | 12×30 mm 的纸能写多少 |
| --- | --- | --- |
| **横版**（默认） | 沿纸带长度方向，一行写满为止 | 1~2 行，每行约 7 个字 |
| **竖版** | 沿纸宽方向，一行写满往下换行 | 7~8 行，每行 4~5 个字 |

竖版就是把纸"竖过来"用：文字在 12 mm 宽度内换行，二维码和条码排在文字下方。
适合竖着贴在机箱侧面、货架立柱这类窄长位置的标签。

> 竖版纸宽只有 84 个点，一行放不下太多字。如果某行太长，字号会**自动缩小**
> 到刚好放下，提示区会写「字号已缩到 15，让最长的一行放进 84 点宽」。
> 这个自动缩放不会改掉你设定的字号，切回横版还是原来的值。

忘了上次打的是什么可以从这里找回来。


## 五、先打一张测试页

第一次用建议先点 **打印测试页**：

- 测试页上有个**三角形**，它指向的是标签**起点**（先出纸的那一端）。
- 如果出来的字是上下颠倒的，把「方向」改成 **旋转 180°** 再打一张。
- 调对一次就不用再动了。

**走纸一张** 会吐出一张空白标签，用来对齐纸张间隙。

## 六、协议调用记录（排查用）

程序一启动就自动记录每一次连接、发送命令、收到应答，**两处都能看到**：

- **控制台**：就是你双击 `.bat` 后弹出的那个黑窗口，实时滚动
- **`打印记录-年月日.log`**：程序目录下，内容更全（包含每一条位图行）。
  按天分文件、追加写入，**不会像以前那样每次启动就把上一次的记录清掉**；只保留最近 14 天

每条记录都把封包翻译成人能看懂的话，例如：

```
[10:36:24.471] ** 型号 ID=2320  电量=100%  固件=10.55  →  打印流程 B1
[10:36:24.474] ** —— 开始打印：96×240 点，1 份，浓度 2，流程 B1 ——
[10:36:24.476] >> 55 55 01 07 00 01 ...   PrintStart 7字节 总页数=1 颜色=0
[10:36:24.477] >> 55 55 13 06 00 f0 ...   SetPageSize 6字节 rows=240 cols=96 copies=1
[10:36:24.519] ** 位图数据发送完毕：240 行，非空白 149 段，黑色点阵共 1861 点（正常）
[10:36:24.520] << 55 55 b3 09 00 01 ...   PrintStatusResp 当前页=1 进度=100%/100%
[10:36:24.521] ** —— 打印完成 ——
```

**打完一张后，请把当天的 `打印记录-年月日.log` 发给我**，我能直接看出卡在哪一步：

| 记录里看到 | 说明 |
| --- | --- |
| `打印流程 D110` | 型号没识别对，D110_M 应该是 `B1` |
| `黑色点阵共 0 点（⚠ 图像几乎全白）` | 内容没渲染上去，是软件问题 |
| `PrintStart 1字节` | 流程不对，D110_M 要 7 字节 |
| `SetPageSize 4字节` | 流程不对，D110_M 要 6 字节（带份数） |
| `PrintStatusResp 当前页=0 进度=0%/0%` | 打印机收到数据但没动，可能是纸张/标签类型设置问题 |
| `!! 打印机错误 2 (缺纸)` | 纸没装好或间隙没对上 |
| `等待命令 0x?? 的应答超时` | 通信断了，换 USB 或重连 |

## 常见问题

**打出来了但纸上没字（走纸正常、程序显示打印完成）**

> 如果你是在**修复行号 bug 之前**的版本遇到的，请先更新到当前版本再试——
> 那个版本展开合并行时行号不递增，打印头一直在同一行加热，必然出空白。

更新后仍然不出字，就点 **诊断页**，它从标签起点到末端依次印五段：

| 段落 | 作用 | 如果这块是白的 |
| --- | --- | --- |
| ① 整块全黑 | 看打印头到底加热不加热 | **纸装反了**（热敏涂层朝下），或纸张类型选错 |
| ② 横向条纹 | 测 96 个打印点的对齐 | 打印头排线/脏污 |
| ③ 纵向条纹 | 测走纸步进 | 走纸机构问题 |
| ④ 文字 TEST | 测字体渲染 | 软件问题，把日志发我 |
| ⑤ 棋盘格 | 测整体位图通路 | 软件问题，把日志发我 |

**判断方法**：

- 五段**全白** → 纸装反了。热敏标签只有一面有涂层，翻过来重装再打。
- ①黑②③有条纹但**④没字** → 数据通路正常，是文字渲染问题，发日志给我。
- ①**整块黑**说明打印头好的，问题在位图数据，发日志给我。

另外可以在「高级 / 校准」里把「打印协议」手动切到 **B1** 再打一次——
你的机器识别为 D110_M + 协议 v4，程序自动选了 `D110M_V4` 流程；
如果这台固件想要的是 `B1` 流程，切过去就能出字。

> 顺带说明：从你的日志看，打印机**确实在打印**（进度从 2% 走到 100%、页数到 1、
> 320 行位图全部发出并收到应答），所以通信这一层是通的，问题在出图这一层。

**USB 串口连不上（提示握手失败 / 超时）**

日志里会给出具体诊断，对照着看：

| 日志提示 | 含义 | 怎么办 |
| --- | --- | --- |
| `探测到 NIIMBOT 打印机：D110-xxx` | 认出机器了，但它在**关机充电模式** | **把打印机开机**，再点连接 |
| `串口完全没有回音` | 这个 COM 口不是打印机，或 USB 只供电 | 在设备管理器→端口确认；不行就**改用蓝牙** |
| `串口有回音但不是预期格式` | 有设备但不是 NIIMBOT | 换正确的 COM 口，或改用蓝牙 |

> 很多 D110 的 USB **只供电不传数据**。插上后如果在「设备管理器 → 端口 (COM 和 LPT)」
> 里**看不到** COM 口，那就是只能用蓝牙。

**一次打印出了两张标签**
- 多半是**标签长度和纸上标的不一样**。比如纸是 30mm，你却选了 40mm，
  内容就会跨到第二张纸上。请把「标签长度」改成和纸卷一致。
- 也可能是「纸张类型」不对：带底纸的间隙标签选「间隙标签」，
  连续的整卷纸选「连续标签」。

**扫描不到蓝牙设备**
- 打印机要开机、有电、盖子合上。
- 关掉手机上的 NIIMBOT App。
- 设置 → 隐私和安全性 → 无线电 → 打开「允许应用控制设备无线电」。
- 把打印机靠近电脑，再点一次扫描。

**点打印没反应 / 提示超时**
- 看日志区的最后几行，会写明哪一步失败。
- 蓝牙信号不稳时可改用 USB 串口。
- 确认标签纸装反了没有、纸卷有没有卡住。

**条码扫不出来**
- 条码要留够高度，浓度调到 3 试一试。
- Code128 最稳；EAN-13 需要 12 位数字。

## 协议说明

封包格式 `55 55 | CMD | LEN | DATA | XOR | AA AA`，校验和为
`CMD ^ LEN ^ 各 DATA 字节`；`Connect` 命令整包额外前置 `0x03`。

打印流程对齐 NiimPrintX 的真机验证实现：
`SetDensity → SetLabelType → PrintStart → PageStart → SetPageSize →
PrintQuantity → 逐行位图 → PageEnd（重试到接受）→ 轮询 PrintStatus → PrintEnd`。

**不发送 `PrintClear`（0x20）**——该命令会导致重复出纸；每行数据
`repeat=1` 不做合并，与 NiimPrintX 保持一致。

图像按 203 dpi 二值化，打印头 96 点（12 mm）。横版画布宽=标签长度、
高=96 点，编码前上下翻转一次以抵消编码器的 Y 轴翻转，使出纸方向与预览一致。

协议细节参考 [niimbluelib](https://github.com/MultiMote/niimbluelib) 与
[NiimPrintX](https://github.com/labbots/NiimPrintX) 的逆向成果，仅供学习使用。
